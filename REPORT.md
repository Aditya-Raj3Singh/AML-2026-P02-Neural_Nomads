# Final Report — Next-Day Air Quality Prediction for Delhi

## 1. Objective
This project evaluates whether previous pollutant readings and calendar information can forecast next-day PM2.5 concentration and next-day AQI category for Delhi. The key comparison is persistence: predicting tomorrow's PM2.5 as today's observed PM2.5.

## 2. Data and scope
The analysis uses the Air Quality Data in India dataset (2015–2020), specifically `city_day.csv`. Delhi was selected because its daily series is comparatively complete and spans a broad range of PM2.5 values. The Delhi data contains 2,009 daily records from 2015-01-01 through 2020-07-01, with no missing calendar dates and no duplicate city-date records.

## 3. Exploratory analysis and missing data
The Phase A EDA reports 2,007 observed PM2.5 values out of 2,009 (0.10% missing). Missingness is concentrated in earlier years. Xylene has 38.88% missing values overall and near-total gaps in 2016–2017; it is a candidate for exclusion. SO2, O3 and PM10 also have notable missingness in 2017. The EDA plots show winter PM2.5 spikes and include the initial COVID-19 lockdown period in 2020. The plot observations should be described as associations visible in the data, not proof that a single event caused the changes.

The documented policy is to leave target values unimputed, keep a continuous daily index, avoid automatically forward-filling long gaps, and fit median imputation for predictor values within training pipelines only. The policy should be kept consistent with the final notebook execution and the actual feature list.

## 4. Feature engineering and split
The corrected Phase C feature table contains 2,009 dates and 80 columns, including 76 predictor features plus date, persistence reading and two next-day targets. Predictors include lags 1, 2, 3 and 7 days for the selected main pollutants, 3-day and 7-day rolling means and standard deviations, and calendar features including month, weekday, and cyclic day-of-year sine/cosine. Rolling windows are shifted before aggregation so they end at the previous day. The notebook includes a hand-check of a rolling mean and the next-day target.

The target is formed with `shift(-1)`: the row at date t is paired with the PM2.5/AQI bucket at t+1. The split is chronological: training target dates are before 2020-01-01 and test target dates are 2020-01-01 through 2020-07-01. The final regression comparison contains 183 test targets.

## 5. Regression results
The supplied corrected Phase C run reports the following results on the same 183 test rows:

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Persistence | 19.745 | 29.453 | 0.721 |
| Ridge | 25.354 | 34.865 | 0.609 |
| Linear Regression | 25.677 | 35.027 | 0.605 |
| Lasso | 25.760 | 35.433 | 0.596 |
| Random Forest Regressor | 29.875 | 40.894 | 0.462 |

Persistence is the strongest regression method by MAE, RMSE and R². Ridge is the best machine-learning regression model by RMSE, but its RMSE is 18.38% higher than persistence's; its MAE is 28.40% higher. Therefore, the current model run does not beat the baseline. The result should be reported transparently. One plausible limitation is that the ML predictors are deliberately restricted to readings through t−1, whereas persistence uses the more recent reading from day t; this makes persistence a strong and information-advantaged benchmark under the current feature convention.

The largest errors for Ridge occur around abrupt changes, including early January and late January/February 2020. This is consistent with the difficulty of forecasting sharp pollution transitions from historical lag features. The final evaluation notebook produces a predicted-versus-actual plot and a table of largest absolute errors.

## 6. Classification results
The next-day AQI bucket was classified using Logistic Regression, Decision Tree and Random Forest, with class weights to address imbalance. In the supplied run:

| Model | Accuracy | Macro-F1 | Mean one-vs-rest AUC (available classes) |
|---|---:|---:|---:|
| Random Forest Classifier | 0.617 | 0.436 | 0.853 (5 classes) |
| Decision Tree | 0.377 | 0.370 | 0.715 (5 classes) |
| Logistic Regression | 0.607 | 0.359 | 0.799 (5 classes) |

Random Forest has the highest macro-F1 in the supplied results. Accuracy alone is insufficient because the AQI buckets are imbalanced and performance differs substantially by class. The test set contains 98 Moderate, 35 Poor, 25 Satisfactory, 22 Very Poor and only 3 Severe observations; no Good observations appear in the test period. AUC is therefore evaluated only for classes with both positive and negative examples in the test set. Although the reported Severe recall is 1.00, it is based on only three examples and should not be treated as reliable evidence of warning performance. Confusion matrices, class-wise precision/recall/F1 and one-vs-rest ROC/AUC are generated by the model/evaluation notebooks.

## 7. Limitations
- The data covers one city and ends in July 2020; the test period is relatively short.
- Missingness is concentrated in earlier years and may not be random.
- Sudden pollution spikes are difficult to predict from lagged values.
- Rare AQI buckets have very small test support, making per-class scores unstable.
- AQI is derived from pollutant concentrations, and the model's classification results should not be interpreted as causal or as an operational public-health system.
- This is a retrospective offline evaluation; prospective validation, calibration, cost-sensitive threshold selection and external testing are needed before real-world use.

## 8. Conclusion
For the supplied corrected run, the persistence baseline outperforms all four regression models. Thus, the project does not demonstrate a regression improvement over the simple “tomorrow equals today” rule on the chosen test period. For AQI bucket classification, Random Forest achieves the highest macro-F1 among the three evaluated classifiers, but rare-class uncertainty remains substantial. The most defensible conclusion is that the pipeline is a useful experimental comparison, while further work is required before it could support a public-health warning.
